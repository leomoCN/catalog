图片补充

批量补齐产品四视角图片：多选或拖拽图片文件（文件名规范 型号_颜色_视角.jpg，如 LP2136_黑色_正面.jpg），自动解析型号 / 颜色 / 视角并在浏览器本地预检（1200×1500 JPEG、≤20MB），预览后批量新增颜色并上传。上传失败时自动回滚已成功的条目；全成功的批次可在「撤销整批」或每行「撤销」手动回滚（新增槽位删除、替换槽位恢复备份原图）。同时支持按分类 / 审核就绪度筛选，每款产品展示分类、就绪度与快速审核动作（公开 / 待审核 / 隐藏 / 清除覆盖 / 编辑）。

批量上传

拖拽或点击选择 多个图片文件（支持多选，文件名按 型号_颜色_视角.jpg 解析）

图片标准化

0 / 0

浏览器本地图片标准化工具：多选任意图片，逐张调整「填充裁切 / 完整适配」、拖动裁切区域（图像随指针移动）与缩放，可用箭头按钮微调取景，每张可自定义导出文件名，按统一 1200×1500（4:5） 导出 JPEG。全部在浏览器内完成，不上传、不调接口、不写服务器；导出后可再到「产品资料 → 编辑 → 产品图片」上传。适合把非标准尺寸的素材图先统一成产品图规格。

已处理 0 / 0 张

拖拽或点击选择 多张图片（JPEG / PNG / WebP，浏览器可解码即可）

图片巡检

只读查看已拍摄图片的槽位与完整度（每色最多四视角，允许部分完整）；日常图片维护请在「产品资料 → 编辑 → 颜色管理 / 产品图片」中操作：先新增颜色，再为缺失视角上传图片，已有视角可替换或删除（删除会自动备份原图）。图片必须 1200×1500、≤20MB。
